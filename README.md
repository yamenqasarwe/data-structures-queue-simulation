# Data Structures – Queue Simulation

A C++ Data Structures assignment that simulates customers arriving at a shopping store and waiting in a queue.

## What the program does

- Uses an array-based queue.
- Generates 0–3 customers each minute.
- Each customer has an ID and arrival time.
- Each customer randomly chooses one of four items.
- Serves one customer per minute.
- Calculates waiting times and other store statistics.
- Tracks out-of-stock customers and store income.
- Calculates the time and number of customers needed to empty the store.

## Technologies

- C++
- Array-based Queue
